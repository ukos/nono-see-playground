# SEE — walk through the world

nono が広い世界をただ歩いて旅する、戦わないRPG（企画No.10）。ブラウザゲーム（HTML＋JavaScript）。

- 遊ぶ：https://ukos.github.io/nono-see-playground/
- 操作：← → で歩く ／ Space で話す ／ J で旅日誌（画面下のボタンでも可）
- 進み具合はブラウザに自動保存（タイトルの「旅をつづける」）

## ファイル
- `index.html`：画面と見た目
- `game.js`：ゲーム本体（移動・描画・会話・旅日誌・天候・セーブ）
- `world.js`：世界のデータ。**国を増やすときはここに1件足すだけ**（項目の説明はファイル冒頭）
- `assets/far/`：遠景（HD-2D Lite 由来）
- `assets/buildings/`：建物・橋（本作用に生成、65点＋）
- `assets/actors/`：住人の顔（Stage Actor の役者）、ユイとレイの衣装、エージェントのシート
- `assets/props/`：木・岩・鳥居・灯台など79点（斜め見下ろしの `iso_*` は横スクロールでは未使用）

## いまある国（16）
国名は実在の国をもじったもの（かっこ内はその土地の呼び名）。

オランジェ（花野の村）→ ジャポネ（竹の里）→ キャセイ（紅灯の都）→ モンゴーラ（風の草原）→ インダスタン（色の都）→ サハリア（砂の国）→ グレシア（白壁の港）→ ブリテニア（霧の島）→ ノルヴィーク（雪の村）→ チリーノ（坂の港）→ シャムラ（水上の町）→ ネーデラ（風車の低地）→ ボリビアナ（塩の湖）→ ネパラ（雪の峰）→ イタリカ（ぶどうの丘）→ ケニアラ（朝日の草原）

## 登場人物
- 住人：Stage Actor の役者（顔の立ち絵）
- ユイ、レイ：国ごとに衣装を変えて登場（`assets/actors/yui_*.webp`, `rei_*.webp`）。正体がわかると呼び名が変わる
- WATCH のエージェント：ファースト、セカンド、少年時代のセカンド（全身ドット絵のシート）

各国に住人2〜4人と、短いエピソード、nono の「気づき」が1つ。行きと帰りで会話や景色が変わる。国ごとに話の骨組みを変えている（噂の確かめ、二重の秘密、歩くことが話になる、物々交換、大事件など）。

## 天候
晴れ・小雨・スコール・台風・強風・霧・濃霧・雪。国ごとに起こりやすさを `weather` で指定し、時間とともに移り変わる。強風と台風では向かい風で歩みが重くなる。

## 素材の出所
- 遠景・nono 歩行・森のシルエット・前景の草・ウサギ：ukos/nono-hd2d `lite/assets/`
- 住人の顔：ukos/nono-playground `stage-actor/actors/`
- 建物・橋・タイトルロゴ・アイコン：本作用に生成

## 遠景（assets/far/）
国の `far` に名前を書くと使える。名前の末尾は時間帯（morning / noon / night。無印は夕暮れ）。
未使用のものは、次に増やす国に割り当てる。

## シナリオチェック（8観点×8軸・SEE版）
国を足すときは、惰性で量産しないために、必ずこのチェックを通す。仕様は `docs/review-spec.md`。

```
node tools/tx.js                                  # 台本を review/tx/ に書き出す（行きと帰りを実際に歩いた順）
node tools/check.js                               # 機械チェック（素材・ID・フラグ・60字・骨組みの使い回し・帰り道の差・解決後に残った解決前の台詞）
node tools/review_check.js review/results/03.jsonl # レビューの引用が台本にあるか照合
```

- `review/results/01.jsonl`：書き直す前の11か国（合格0）
- `review/results/02.jsonl`：書き直したあとの11か国（全国合格）
- `review/results/03.jsonl`〜`05.jsonl`：新しい国（ネーデラ、ボリビアナ〔28点で一度保留→直して合格〕、ネパラ、イタリカ、ケニアラ）
- 合格しなかった国は公開せず `docs/drafts/` に置く
- 役者（立ち絵）が足りないため、同じ役者を別の住人に使うときは6か国以上あける（機械チェックでエラー）
- 採点は書いた本人（Claude）がしているので甘くなりやすい。外部のレビュー（人や別のAI）で確かめるのが望ましい

## 役者の方針
- 住人は人間が基本。十二支を含むライバル15人、妖怪、骸骨、人魚・エルフなど人間でない者はストック（tools/check.js の STOCK）。
- 出すときは特別枠にする。npc に `special: 'legend'`（うわさの正体が本当にいた）か `special: 'guest'`（ライバル本人のゲスト出演）を付ける。
- 特別枠は10か国に1か国まで、5か国以上あける。超えると check.js がエラー／注意を出す。

## 乗り物の決まり（walk through the world）
- 乗り物は、歩いて越えられない所だけ。国に `ride: 'ship'`（海を越える船旅、`sea: true` も付ける）か `ride: 'self'`（自分で漕ぐなど、自分の力で渡る）を付ける。
- 陸で馬車・汽車・荷車・渡し舟などに乗って運ばれる話は作らない。乗り物は住人の暮らしとして風景に出すだけ。
- 船旅は15か国に1か国、自分で渡る国は30か国に1か国が目安。乗り物の国どうしは8か国以上あける。
- 乗り物の上でも、nono は歩いて人と話す。
- tools/check.js が、上限・間隔・ride のない国で nono が乗り物に乗る描写を検査する。

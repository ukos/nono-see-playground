## 3. 特に見てほしいこと

1. **前回の弱点が直ったか。** 前回は「小さな賭け」と「入り」が弱いという指摘でした。住人が何を失うと困るのかが分かるか、最初の相手が小さな謎や困りごとを出しているか、を見てください。
2. **新しい癖が出ていないか。** 直すときに同じ手を何度も使っていないかを見てください。
   - 入りの問いかけ（「〜は何だと思う？」「手を見せて」）が型になっていないか
   - 気づきの文が、また同じ形にそろっていないか
   - 「帰り道に、住人が少し成長している」という締めが続きすぎていないか
3. **新しい国4つ（カモメ号、マロッカ、イスパーニャ、ウクリーナ）の固有性。** その国でしか起きない話か、既存の16か国と骨組みが重なっていないかを見てください。
4. **特別枠の扱い。** グレシアの人魚は、特別枠（伝説）として出しています。ほかの国には、人間でない者は出ていないはずです。

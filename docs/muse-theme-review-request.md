# Muse への依頼：100か国の全体レビュー（テーマとの一致）

## お願いしたいこと
SEE は 100か国になりました。1か国ずつの採点（docs/review-spec.md の8観点×8軸）は、すべて合格しています。
今回は国ごとの出来ではなく、**100か国を通して読んだときに、ゲームのテーマに合っているか**を見てください。

## ゲームのテーマ
タイトルは「SEE ― walk through the world」。nono が広い世界を、ただ歩いて旅する、戦わない RPG です。
画面は横から見た 2D で、旅人は東へ歩き、世界の果て（100か国目）で折り返して、同じ道を西へ帰ります。
帰り道では、住人の台詞や景色が変わります。最初の国まで帰ると「おかえり、nono」の画面で旅が終わります。

テーマを、次の8つの柱に分けて見てください。

| # | 柱 | 合っている状態 |
|---|---|---|
| 1 | 歩く | 歩くこと・歩いた距離・足で確かめることが、話の中で意味を持つ。乗り物は最小限（船旅は海を越える所だけ） |
| 2 | 戦わない | 悪役・暴力・勝ち負けで解決しない。対立があっても、ほどける形で終わる |
| 3 | 見る（SEE） | 場所を見る・聞く・読むことで気づく。説明を聞くだけで解ける話になっていない |
| 4 | 旅人の距離 | nono は通りすがりのよそ者。住人の問題を代わりに解きすぎず、住人が自分で動く。旅人は去っていく |
| 5 | 行きと帰り | 帰り道で、同じ場所が違って見える。帰りが「後日談の報告」だけになっていない |
| 6 | 気づき | 旅日誌に残る一文が、説教や格言の言い換えではなく、その国で見たものから生まれた発見になっている |
| 7 | 世界の広さ | 100か国が、土地ごとの暮らしの手ざわりで書き分けられている。文化の描き方が型どおり（ステレオタイプ）になっていない。もじった国名や暮らしの描写に敬意がある |
| 8 | 日常の大きさ | 主役は人間の普通の暮らし。事件は小さく、でも本人には大きい。特別な存在（人間でない者）は、まれな特別枠だけ |

## 読むもの
- 台本：`review/tx/<国ID>.txt`（100ファイル）。各ファイルの2行目に「N番目の国」とあるので、その順に読んでください。
- 国の並びと骨組みの一覧：`world.js` の各国の `shape`（骨組みの名前）
- 決まりごと：`README.md`（住人の決まり・乗り物の決まり）、`docs/review-spec.md`
- 1〜20か国目あたりは、初期に作った国です。後半とのちがいも見てください。

`review/results/` は見ないでください。台本だけで判断してください。

## 特に見てほしいこと
1. **くり返しの型**：100か国を通して、同じ運び方がくり返されていないか。たとえば次のような型です。それぞれ、何か国くらいで使われているかも数えてください。
   - 真ん中の住人が、事情を説明して次へ案内するだけ
   - 子どもが答えを知っていて、大人が気づかされる
   - 亡くなった人の思い出が鍵になる
   - 昔の出来事（祖父母の若いころ）が明かされて解決する
   - 旅人が伝言を運ぶだけで解決する
2. **nono の役回り**：nono が解決しすぎていないか。逆に、ただの伝言係になりすぎていないか。国ごとの割合の印象でかまいません。
3. **歩くことの扱い**：「歩く」がテーマなのに、歩くことが話に関わらない国が多すぎないか。歩くことが中心の国（例：モンゴーラ、エクアドラ、ミャンマナ、クロアチナ、フエギナ）が、全体の中で効いているか。
4. **文化の描き方**：特定の土地を、貧しさ・未開・異国趣味だけで描いていないか。気になる国があれば、具体的な台詞を挙げてください。
5. **旅の始まりと終わり**：1か国目（オランジェ）で旅が始まる感じと、99〜100か国目（ケープナ、フエギナ）で折り返す感じが、テーマに合っているか。「おかえり、nono」の画面の文言（下に書きます）も見てください。

「おかえり、nono」の画面の文言：
```
おかえり、nono
世界の果てまで歩いて、来た道を、ここまで歩いて帰ってきた。
歩いた国 ○ ／ 100　・　気づき ○
来た道は、行きと同じ道なのに、同じには見えなかった。
```

## 出力の形
次の3つを、この順で出してください。

### 1. 全体の採点（JSON 1行）
```json
{"scope":"all","pillars":{"walk":0,"nofight":0,"see":0,"distance":0,"roundtrip":0,"insight":0,"breadth":0,"everyday":0},"total":0,"patterns":[{"name":"型の名前","count":0,"examples":["国ID","国ID"]}],"nono_role":"解決しすぎ／ちょうどよい／伝言係すぎ のどれかと一言","ending":"始まりと終わりの評価を一言"}
```
- `pillars` は各柱を 1〜5 で。5 はテーマの手本、3 は合っているが弱い、1 は外れている。
- `patterns` は、上の「くり返しの型」に加えて、ほかに見つけた型もあれば入れてください。

### 2. 気になる国（JSON Lines、最大15行）
テーマから外れている、または弱い国だけを挙げてください。合格している国の細かい弱点は不要です。
```json
{"id":"国ID","pillar":"walk など柱の名前","issue":"何が外れているか（引用は台本の文そのまま、60字以内）","suggest":"直す方向を一言"}
```

### 3. 所見（400字以内）
100か国を通して読んだ印象。テーマにいちばん合っている国を3つ、いちばん弱い国を3つ、理由つきで。

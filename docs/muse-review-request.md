# レビュー依頼：SEE の国と地域シナリオ（8観点×8軸）

Muse へ。旅RPG「SEE ― walk through the world」の国と地域16か国のシナリオを、決まった物差しでレビューしてください。

16か国とも制作側で自己採点をして、すでに全国が合格になっています。ただ、作った側の採点なので甘くなっているおそれがあります。外の目で採点し直してもらうのが今回の目的です。

---

## 1. SEE について（前提）

- 横スクロールで世界を歩く、戦闘のない旅RPGです。主人公は旅人の nono です。
- 1つの国は横4〜8画面ぶんの長さで、会話が中心です。nono は住人の日常に少しだけ関わって、先へ進みます。
- 世界の東の端まで歩いたら、西へ戻ってきます。同じ場所の意味が、行きと帰りで変わることが作品の核です。
- 国の名前は、実在の国をもじったものです（オランジェ、ジャポネ、ブリテニアなど）。
- 住人は人間が基本です。人魚やライバル本人のような人間でない者は、「特別枠」としてごくまれにしか出ません。

公開リポジトリ：https://github.com/ukos/nono-see-playground （ブランチ main）

   `docs/review-spec.md`
   https://raw.githubusercontent.com/ukos/nono-see-playground/main/docs/review-spec.md
2. **台本（各国1ファイル）**
   `review/tx/<国ID>.txt`
   例：https://raw.githubusercontent.com/ukos/nono-see-playground/main/review/tx/hanano.txt

台本は、旅人が実際に歩いた順に会話を書き出した記録です。〔行き〕と〔帰り〕の区別、書式、国をまたぐ前提の読み方は、物差しの §3 に書いてあります。

**見ないでほしいもの**
- `review/results/`（制作側の自己採点）
- `world.js`（ゲームのデータそのもの）

独立した採点にしたいので、この2つは開かないでください。

## 4. やってほしいこと

1. 物差し（`docs/review-spec.md`）を読む。
2. 16か国の台本を1つずつ読み、次の4つを付ける。
   - 8観点：○・△・×
   - 8軸：1〜5点
   - 感情曲線：会話ごとに5指標を1〜5
   - 不具合：問題の台詞を引用して書き出す
3. 判定ゲートは物差しの §5 のとおりに当てはめる。
4. 最後に、16か国を通して見たときの全体の所見を書く。

### 採点で特に意識してほしいこと

- **物差しどおりに、辛めに付ける。** 3点が「ふつう」、5点は「際立って良い」です。5点はめったに付けないでください。迷ったら低いほうを選んでください。
- **国ごとに違う話になっているか。** 量産で生まれやすい弱点を見逃さないでください。
  - 名前と小道具を差し替えれば別の国でも成り立つ話
  - 同じ骨組みの繰り返し（半分ずつ話して、最後に格言で締める型など）
  - 気づきの文が、毎回同じ形の教訓になっている
- **引用のない指摘は無効です。** 不具合の `quote` は、台本にある文字列をそのまま写してください。制作側で、引用が台本に実在するかを機械で照合します。
- **役者の見た目は評価しない。** 役者の見た目と役が合っているか、表情が指定どおりかは評価の対象外です。

## 5. 返してほしいもの

### (A) JSON Lines（16行）

1つの国を1行にします。形式は物差しの §8 と同じです。

```json
{"id":"hanano","kanten":["○","○","△","○","○","○","○","○"],"axes":[4,3,3,4,3,4,5,4],"total":30,"gate":"要改善","curve":[{"talk":"長老","tension":2,"expect":3,"laugh":1,"surprise":2,"empathy":2}],"curve_note":"平らな所・繰り返しを一言","note":"強みと最大の弱点を1〜2文","bugs":[{"quote":"台本からそのまま写した台詞","problem":"なぜ問題か"}]}
```

- `kanten` は8観点、`axes` は8軸です。どちらも物差しに書いてある順に並べてください。
- `total` は `axes` の合計、`gate` は「合格」「要改善」「作り直し」のどれかです。
- コードブロック1つに、16行をまとめて入れてください。

### (B) 全体の所見（文章、800字以内）

- いちばん良い国とその理由。弱い国を3つ挙げ、それぞれの理由。
- 16か国を通して見えた、作り方の癖や繰り返し（言い回し、骨組み、気づきの形）。
- 次に国を作るときに、変えたほうがいいこと。3つまで、具体的に。
